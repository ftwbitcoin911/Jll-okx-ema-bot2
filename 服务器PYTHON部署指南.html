JLL · OKX 服务器部署指南

新加坡服务器 · 极简部署流程

🚨 上线前必查：请确认 btc.json 中的周期为 "1D" 或 "6H"，绝不可写 "8H"（OKX不支持，会直接报错退出）。API 权限切勿勾选提现，且需绑定当前服务器IP。
环境准备与 Python 安装 Step 1
登录宝塔面板，打开终端，执行以下命令安装 Python 3.10 及相关工具：
# 更新软件源
sudo apt update

# 安装 Python 3.10、pip 和 虚拟环境模块
sudo apt install python3 python3-pip python3-venv -y

# 验证安装（应显示 Python 3.10.x）
python3 --version
创建虚拟环境与安装依赖 Step 2
进入项目目录，创建隔离环境并安装依赖包：
# 进入项目目录 (请确认实际路径)
cd /www/okx_1k_bot

# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境 (终端提示符前会出现 venv)
source venv/bin/activate

# 安装依赖 (使用清华源加速)
pip install --upgrade pip
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
单次试跑测试 Step 3
配置好 btc.json 后，先单次运行，观察日志是否报错：
# 单次对账并退出，不进入死循环
python3 okx_1k_bot.py -c btc.json --once

# 查看日志（按 q 退出）
cat btc.log | less
* 若日志出现 [启动预检] K线接口正常 和持仓信息，则链路跑通。
宝塔守护进程 Step 4
在宝塔面板中实现 7x24 小时常驻：
  • 软件商店 → 安装 Python项目管理器。
  • 添加项目，路径选 /www/okx_1k_bot。
  • 启动命令填：/www/okx_1k_bot/venv/bin/python /www/okx_1k_bot/okx_1k_bot.py -c btc.json。
  • 勾选“自动重启”与“开机自启”。
日常维护与实盘确认 Step 5
  • 查看实时日志： tail -f /www/okx_1k_bot/btc.log
  • 检查持仓状态： cat /www/okx_1k_bot/state_btc.json
  • ⚠️ 转实盘最后确认：将 btc.json 中的 "dry_run" 和 "simulated_trading" 改为 false，并在宝塔中重启项目。
